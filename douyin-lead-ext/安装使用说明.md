# 抖音获客采集助手 安装与使用说明（v0.4 · 三接口直读版）

> 功能：在 Chrome 打开抖音视频页面，自动采集评论区用户信息，一键导出与《行业作品意向匹配》相同格式的 Excel。
>
> **v0.4 升级**：插件注入页面同时监听**三个接口**的响应，一次采集拿到全部有效信息：
> 1. `comment/list` 评论列表 → 昵称、抖音号、uid、评论内容、精确时间、属地
> 2. `user/profile/other` 用户主页 → **粉丝数、关注数、获赞数、作品数、性别、省份、城市、认证、个性签名**
> 3. `aweme/detail` 视频详情 → **视频点赞/评论/分享/收藏数、视频描述、作者与作者粉丝数**
>
> 无需破解 msToken / a_bogus 签名——页面自己会带签名请求接口，插件只"蹭读"响应，风控风险最低。

## 一、安装（约 1 分钟）

1. Chrome 地址栏输入 `chrome://extensions` 回车。
2. 打开右上角 **「开发者模式」** 开关。
3. 点击左上角 **「加载已解压的扩展程序」**，选择 `douyin-lead-ext` 文件夹。
4. 点插件卡片上的红色音符图标 📍 固定到工具栏。

> **更新插件版本**：替换文件后，回到 `chrome://extensions` 点插件卡片上的 🔄 重新加载，**并且要 F5 刷新抖音视频页面**。

## 二、使用流程

### 前置条件
- **先登录抖音网页版**（douyin.com 扫码登录），否则评论接口不给数据。

### 步骤
1. 打开目标视频页面，复制地址栏链接。
2. 点插件图标打开弹窗：
   - **视频链接**：粘贴链接（`https://www.douyin.com/video/数字ID`）。
   - **意向关键词**：默认预置常用意向词，命中即标记触发词。
   - **采集主题**（可选）：写入 Excel「关键词」列。
   - **高级设置**：滚动间隔（默认 2 秒）、连续几轮无新数据后停止（默认 5）。
3. 点 **「▶ 开始采集」**：插件自动滚动评论区，页面自动分页加载，插件直读每页接口数据；同时视频详情接口数据自动入库。弹窗实时显示进度（已入库条数、API 页数/评论数、视频总评论数）。接口到最后一页自动结束。
4. （可选）点 **「👤 补全主页资料」**：后台逐个打开评论者主页，抓取**粉丝数/关注数/获赞数/作品数/性别/省份/城市/认证/签名**（接口拦截自动入库，拦截失败自动 DOM 兜底）。补全期间保持弹窗打开。
5. 点 **「📥 导出 Excel」**：生成 `行业作品意向匹配-日期.xlsx`，包含两个工作表：
   - **Users**：前 14 列与你的原表完全一致，后面追加 8 个扩展列（粉丝数、关注数、获赞数、作品数、性别、省份、城市、认证）；
   - **视频数据**：每个采集过的视频的点赞/评论/分享/收藏数、描述、作者、作者粉丝数。

## 三、技术原理（和"别人那个软件"一样）

```
抖音页面滚动时自动带签名请求接口
        │  XHR/fetch 钩子（content-main.js 注入页面主世界）
        ▼
截获三个接口响应 JSON（评论/主页/视频详情）
        │  postMessage 桥接
        ▼
content.js 解析 → 关键词过滤 → 去重 → chrome.storage 本地存储
        ▼
一键导出 Excel（线索 + 视频数据两张表）
```

## 四、常见问题与排查

| 现象 | 处理 |
|------|------|
| 点了开始没反应 | ① 弹窗点「🔧 自检」；② 插件刚装/刚更新时旧视频页不会注入脚本 → **F5 刷新视频页**；③ 视频页 F12 控制台输入 `__DY_LEAD__`，打印出版本号 v0.4.0 说明已注入 |
| 提示"检测到登录墙" | 去 douyin.com 登录后重新开始 |
| 调试区显示「DOM模式」而非「API直读」 | 接口没被捕获：确认已登录、评论区能正常加载；把控制台 `[dy-lead]` 日志发我 |
| 扩展列为空 | 没有点「补全主页资料」，或该用户主页被风控拦截 |
| 采集到一半停 | 重新点开始即可，已入库自动去重 |

**后台日志**：`chrome://extensions` → 插件卡片 → 「Service Worker」链接 → 看 `[dy-lead][bg]` 日志。
**页面日志**：视频页 F12 控制台，`[dy-lead][api]` 前缀的是接口捕获日志。

## 五、安全与合规提示

- 数据只存本机浏览器（chrome.storage.local），不上传服务器；及时导出 Excel。
- 默认 2 秒滚动间隔较安全，不要对大量视频高频连续采集。
- 用户信息仅用于对**已公开评论表达意向的用户**的业务沟通，遵守《个人信息保护法》与抖音平台规则，控制触达频率。

## 六、文件清单

```
douyin-lead-ext/
├── manifest.json        # 插件配置（MV3，含 MAIN world 注入声明）
├── background.js        # 后台：存储/去重/调度/主页补全
├── content-main.js      # 页面主世界：XHR/fetch 钩子，拦截三个接口响应
├── content.js           # 页面隔离世界：滚动驱动、数据解析、DOM 兜底
├── popup.html/.css/.js  # 弹窗界面（含环境自检）
├── lib/xlsx.full.min.js # Excel 导出库（SheetJS）
└── icons/               # 图标 16/48/128
```
