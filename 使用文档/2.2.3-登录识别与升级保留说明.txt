华贸获客 2.2.3：登录识别与升级保留说明
更新日期：2026-10-08
发布状态：正式发布包与本机升级验收完成。

一、为什么浏览器已经登录，采集却提示未登录
本次定位到程序的登录识别和状态同步问题。
原有识别把部分本人账户菜单证据限制在 /user/self 本人主页；进入 video / note 作品页面后，即使仍有有效登录会话，也可能漏识别私有账户菜单或图标。
未取得充分证据属于“登录待确认”，旧任务流程却将这一结果合并成“未登录”。账号卡片仍显示上一次确认结果，造成卡片与采集任务不一致。
以上情况不能据此判断是 Google Chrome 丢失登录数据，也无需通过修改 API Key、统一间隔或重新配置服务器解决。

二、统一判断方式与状态同步
登录识别优先使用浏览器当前取得的本人账户接口响应，并核对有效会话、账号浏览器上下文和证据时效；在同一账号、同一会话中进入作品页面后承接已确认的登录证据。
会话改变、退出登录或接口明确返回登录失效时，不继续使用旧证据。未取得可靠证据时显示“登录待确认”，不会直接解释成已退出登录。
账号管理与采集、关注私信任务共用登录检查与状态同步，更新最近检查时间；相同状态通知去重，账号卡片不再沿用与任务不一致的旧结果。
区分已登录、确实未登录、等待扫码或手机确认、安全验证、浏览器关闭以及登录待确认。只有头像或评论接口返回数据，均不足以单独证明本人账户已登录；验证码和平台限制仍由人工处理。

三、响应回执优先与当前能力边界
采集以对应作品的评论、作品详情接口响应入库，仍核对作品标识并去重。登录以可靠的本人账户接口响应优先，页面信息只作为辅助证据。
关注操作增加响应回执识别，要求候选回执与本次目标和 POST 操作相匹配。候选接口及字段尚未验证真实平台契约；未知、拒绝或无法明确归属本次操作的响应均保持“待核验”，不直接认定“确认失败”。仅有 HTTP 200、按钮被点击或页面文字改变，不直接等同业务成功。
未取得明确可靠回执的对外操作保留“待核验”，不会靠推测升级为成功，也不会因结果未确认而自动重复尝试。
当前私信仍缺少经过验证的真实生产响应协议适配。点击发送、输入框清空或页面出现消息气泡，均不作为已成功送达的充分证明；没有可靠回执时保留“待核验”，需核对实际聊天记录后人工确认。
隔离模拟测试用于核对判断、暂停和去重逻辑，不能证明真实抖音关注或私信已经成功。本版不声称所有平台操作都已取得完整、稳定的响应回执。

四、升级后继续使用原设置
安装目录仍为 D:\华贸自媒体获客。退出旧客户端及其账号浏览器后，升级到原目录。
升级时仅替换验收通过的程序文件，保留 config.json 和 data，不清空历史数据。
已保存的 DeepSeek API Key、AI 模型、自定义提示词、采集与关注私信设置、工作休息时间、线索及操作记录继续沿用。
账号浏览器登录资料保留；实际抖音会话是否有效，仍以平台当前结果为准。新增设置项才使用默认值。
请勿先卸载并选择清理数据，也不要把绿色程序包解压到全新目录后误认为旧设置丢失。

五、更新后的操作
打开客户端，在“账号管理”打开原账号窗口。若浏览器已显示本人账户菜单，保持窗口打开并点击“检查”。
确认最新状态后，在采集历史把中断作品加入队列继续采集；已保存线索保留并自动去重。
若显示“登录待确认”，请保持账号窗口打开，待页面正常加载后再次检查；必要时打开本人主页或展开右上角本人账户菜单提供辅助证据。若显示需安全验证，按抖音页面提示人工处理。
