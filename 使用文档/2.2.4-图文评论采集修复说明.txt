一、为什么图文停留在等待，却没有继续收到评论
图文作品打开后，右侧可能默认显示“相关推荐”。页面虽然显示评论数量，但未打开评论面板时，不一定会请求或继续加载评论。
仅滚动整页或图文图片区域，不能保证驱动评论列表翻页。因此应先切换到“评论”，再滚动当前作品的专属评论列表容器，监听由页面正常操作产生的评论接口响应。
评论采集仍以专用账号浏览器收到的响应为依据，不复制分享链接中或开发者工具中的临时签名、令牌参数，不直接重放带临时认证参数的接口地址。

二、本次修复后的行为
进入 video 或 note 作品页面后，检查评论面板状态；未打开时，先通过页面的评论入口切换到评论面板。
后续滚动限定为当前作品的评论容器，避免滚动相关推荐或图文图片区域。页面提供多个滚动区时，不能把任意可滚动元素当成评论列表。
评论响应须对应当前作品标识，线索继续按已有规则去重。作品详情、相关推荐或其他作品的评论响应，不作为当前作品采集进度。

三、如何判断是否真的在推进
采集进展主要看当前作品评论响应中的分页 cursor、has_more 及实际收到的评论页，而不是仅看“第几轮等待”或“新增多少线索”。
同一页反复返回、重复评论或没有新线索，不能直接解释成翻页成功；已有评论全部重复时，也不能仅因新增为零就判定评论已读完。
收到当前作品有效响应且 has_more 明确表示没有下一页，才可以据此结束该作品。页面请求尚未发出或响应尚未收到时，不把轮数用尽当成完整采集成功。
长时间没有有效分页进展时，应暂停该作品并保留已入库数据与继续采集入口，避免一直等待到翻页上限。暂停原因应说明评论面板或分页未推进，便于后续检查。

四、图文描述与 AI 上下文
本次实际只读检查发现，已入库的图文记录缺少 desc、作者及 capturedAt 等详情字段，而视频记录已有作品描述。这说明图文作品详情未完整入库，但不能据此断定抖音为图文使用了不同的描述字段名。
原有程序主要监听单个 detail 接口，图文页面不一定发出该请求，可能遗漏页面已有的详情信息；这不证明图文使用了另一条特定 API 路径。原有详情更新在响应缺少 desc 时，还可能用空值覆盖历史描述。
本次通过应用内部浏览器匿名打开实际图文作品 7693579483274183025，确认其 HTTP 文档包含流式 self.__pace_f 脚本数据。在该次响应中，JSON 数据 row 7 的第 4 项内有 aweme.detail，作品标识为 awemeId，描述仍在 desc 字段；RENDER_DATA 仅含应用状态，没有该作品详情。因此，仅读取普通 JSON script 或 RENDER_DATA 仍可能漏掉图文描述。
该作品实际返回的 desc 为“可以解决 有通过案例的来。亚马逊协议三侵权”；images 长度为 1，图片尺寸 1248×1456，包含 uri，urlList 与 downloadUrlList 各有 2 个 WebP/JPEG 地址候选，images[0].video 为 null。这些是该作品实际文档响应字段，不是公开合成样例；文档不保存带临时签名查询参数的完整图片链接。
字段映射：原始 API 的作品标识通常为 aweme_id，图片地址列表为 url_list；页面已经归一化的数据使用 awemeId 与 urlList，描述仍为 desc。解析必须核对目标作品标识，不能把字段命名差异或图片数组当成另一作品的数据。
新版严格按当前目标作品标识解析详情，优先使用浏览器已有目标作品接口响应中的 desc；必要时从当前页面已经存在的目标作品 JSON、流式 self.__pace_f 脚本中的严格 JSON 数据、明确的作品描述或 URL 匹配的 meta 信息只读补充。流式数据只解析 JSON，不 eval 或执行脚本。不另外请求新 URL，不添加未经验证的候选 API 路径，不把相关推荐或其他作品的文字当成当前作品描述。
新的描述更新保留已有非空描述。仍未取得可靠内容时，明确记录“缺少作品描述”，不把图片内容、标签集合或猜测文本填作完整描述。
AI 判断和线索查询已有 note 作品标识映射；本次同时修复 Excel 导出只匹配 video 链接的规则，使 note 图文可关联对应作品描述。上述解析与关联逻辑已完成代码回归及正式发行程序的隔离验收。

五、使用方法
升级后打开原客户端与原账号浏览器。先确认账号状态，再从采集历史把中断的图文作品加入队列。
本次这条图文历史记录已标为 complete，但尚无作品描述。升级后，请勾选“强制重采”再采该图文，补充作品描述；否则历史完整状态或冷却规则可能直接跳过该作品。原有评论继续按作品、用户、评论文本等现有规则去重，不需要删除历史或已保存的线索。
新版进入作品后会检查并打开评论面板。若平台布局发生变化、评论入口不可用或出现验证提示，请保留现场并查看客户端的暂停原因。
可以人工点开“评论”观察能否加载，但无需手动复制评论接口的完整参数。停止任务始终可用；验证码及账号限制按平台提示人工处理。
已经采集的线索保留，续采仍去重。是否采集完整以本次明确收到的响应和分页结束证据为准。
