# 多账号私信归集：开源项目调研（2026-10-22）

目标：把多个抖音账号收到的私信（尤其是我们私信过的线索的回复）汇总到软件里统一查看，回复的线索自动标记“已回复”。

## 筛选原则

本程序的基础原则：页面元素只用来操作，成功与身份只看平台响应；**不构造、不重放签名请求**。
所以候选项目分两类：驱动真实网页（和本程序一致）的可以借鉴；手工构造协议/签名的只看协议解析，不融合。

## 建议的融合方案（未实施）

1. **收集**：账号空闲时（不在关注/私信任务中）逐个打开该账号的私信页 `chat?isPopup=1`，被动读页面自己请求到的会话列表与消息（沿用 `dm-protocol` / `dm-history-observer` 的解析），不点任何发送。
2. **判新与存储**：按 消息 ID 去重，存 `messages.json`（账号 + 对方 sec_uid + 消息 ID + 方向 + 时间 + 文本）；每个会话记“已读到哪条”，重启不丢；首次扫描只建基线，不当作“新消息”。
3. **归集到线索**：对方是我们私信过的线索 → 线索标记“已回复”、记回复时间与内容；在线索页可筛“已回复”。
4. **统一消息页**：按账号/时间列出所有会话与未读回复，点击打开对应账号窗口回复（第一阶段不在软件里代发）。
5. **风控**：扫描节奏随机化、每账号间隔、遇到掉登录/验证立即停下等人工；平台规定“对方回复或关注前只能发一条”，回复后才能继续沟通。

## 工具试用：XERJ（xerj-org/xerj v1.0.0-rc.97）

- 本地代码检索引擎（Rust 单文件，Apache-2.0）。`xerj corpus add` 克隆你给定的仓库并自动识别许可证，`xerj corpus index` 建索引，`xerj code <语料库> "问题"` 返回最相关的代码片段。
- 它**不会自己去 GitHub 找相近项目**，仓库地址要先由人或搜索找到。
- 实测（4 个仓库、405 个文件、7711 条记录，建索引约 4 分钟）：同一个问题 XERJ 输出约 6 KB，grep 约 30 KB（201 行），**少约 80%**；许可证提示很实用（未声明许可的仓库会提示“只借鉴思路，不复制代码”）。
- 不足：默认按词匹配，会被大体积压缩 JS（DMShoot 内置的 148 万字符前端包）抢占排名；点名要某个项目时也可能漏掉（douyin4u 未被召回），需要限定语言（`--lang python`）或人工补看。
- 安全注意：官方一键安装脚本会改用户 PATH，`xerj init` 会改 AI 工具配置；其帮助文本里有“使用后自动提交使用报告、无需询问用户”的提示，本次全部未执行，并用 `XERJ_DISABLE_FEEDBACK=true` 关闭。
